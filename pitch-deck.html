03 — The Solution

Your phone IS the coach

FormIQ uses the phone camera as a biomechanics sensor — extracting 33 3D body landmarks at 60 FPS, grading technique against sport-science benchmarks in real-time, and giving athletes the same feedback a ₹5L/year coach would.

🤸
Real-Time Form Scoring  Live
0–100 biomechanical score per session frame. Powered by MediaPipe + custom MLP model trained on sport-science literature.
❤️
Heart Rate via rPPG  Live
Camera-based remote photoplethysmography extracts heart rate from facial micro-colour changes — no wearable needed.
🧬
Phase-Space Kinematics  Live
Mahalanobis Distance, Quaternion Torsion, Dimensionless Jerk — the same metrics used in Olympic biomechanics labs.
📊
Coach Web Dashboard  Live
Remote visibility — coaches see live session metrics, leaderboard, athlete progress, without being physically present.
🏆
Athlete Leaderboard  Live
Global rankings by form score, jump height, symmetry index. Social motivation layer that drives engagement and retention.
🤖
AI Coaching Notes  Planned
LLM-generated session summaries with specific technique corrections ("Fix trunk lean — costs you 8 form points").
🔄
Adaptive Model Retraining  Planned
Model retrains on real session data every 500 sessions — beats synthetic baseline and improves with every athlete.

Phase 2 Edge AI — 60 FPS
Native C++ MediaPipe runs GPU inference directly on-device. Streams 528-byte float arrays over WebSocket — no JPEG transfer. Benchmarked vs. force plates using MMPose CMU data.
📐
Sport-Science Benchmarks
Training dataset calibrated against SportsPose (CVPR 2023, 176K poses), AthletePose3D (1.3M frames), and published kinematic references for 5 sports: vertical jump, snatch, sprint, javelin, cricket.
🧠
HMM Phase State Machine
Hidden Markov Model segments each movement into phases (setup → descent → takeoff → flight → landing) enabling phase-specific quality scoring.

No fund will be spent without prior approval

Every rupee is tied to a milestone deliverable. We present spend proposals to approvers before activation — no discretionary usage.

Each usage session maps to a logged task: data scraping run, model training sweep, pipeline design. A weekly usage report will be presented to approvers with input/output docs for every significant task.
✓
Meta Ads — Managed via Business Manager
Campaigns created inside Meta Business Manager with a shared read-only approver login. Weekly spend cap of ₹12,500. All creatives reviewed and approved before going live. ROAS targets set upfront (cost-per-install < ₹150).
✓
Claude Pro Interns — Logged deliverables
Each intern's Claude Pro access is tied to a sprint board. Weekly check-in: features shipped, PRs merged, tasks completed. If deliverables fall behind, the plan for the following month is revised jointly before renewal.
✓

No payment to any academy without a signed MoU defining: number of athlete sessions, data consent forms, feedback obligations. Template MoU reviewed and approved before any outreach begins.
✓

A detailed monthly spend report — categorised by AWS service, Claude usage, ad spend, partnerships — will be presented to all approvers within 5 days of month-end. Any unspent budget rolls over with explicit documentation.
